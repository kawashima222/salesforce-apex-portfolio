## 公開版での証拠方針

- テスト件数、対象範囲、成否、カバレッジなど、設計と品質を説明するために必要な集計値だけを掲載します。
- raw JSON、JUnit XML、HTMLレポート、CLIログはローカルで管理し、公開リポジトリへ含めません。
- 進行中のCP6は、デプロイ・テスト・静的解析が完了するまで検証済みとして扱いません。
