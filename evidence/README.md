## CP6 Security Recipes

学習用のスクラッチ組織で、公開版と同じCP6のApex・権限セットをAPI 67.0で検証しました。以下はその実行結果の集計です。

| 検証 | 結果 |
| --- | --- |
| 実デプロイ | Apex 5件・Permission Set 4件の計9/9成功、エラー0件 |
| CP6のテスト | Query 12/12、Update 17/17 |
| `RunLocalTests`（CP6含む） | 8クラス、123/123成功、失敗0件 |
| Serviceのカバレッジ | Query 15/16箇所（93.8%）、Update 74/76箇所（97.4%） |
| 静的解析 | Critical 0、High 0、Moderate 44、Low 34、Info 11 |

QueryではCRUD・FLS不足で例外になり、共有で見えないAccountは結果から除外されることを確認しました。UpdateではFLSによる項目除去と許可項目の更新、入力不変性、共有不足時の失敗結果、部分成功を確認しました。200件処理の計測結果は、検索がSOQL 1文・200行、更新がDML 1文・200行です。

- テスト件数、対象範囲、成否、カバレッジなど、設計と品質を説明するために必要な集計値だけを掲載します。
